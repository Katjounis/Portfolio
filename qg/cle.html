Clés du QG

Cette page fabrique tes trois clés secrètes directement dans ton navigateur (générateur aléatoire cryptographique). Rien n'est envoyé nulle part : la page n'a même pas le droit de se connecter à internet.

QG_LOGIN_KEY · clé d'accès pour te connecter au QG
QG_DATA_KEY · clé de chiffrement (AES-256)
QG_HOOK_SECRET · secret du pont Google
À faire maintenant

1. Enregistre les trois dans ton gestionnaire de mots de passe (Mots de passe iCloud ou Bitwarden), fiche « QG Katjounis » : la clé d'accès comme mot de passe (ton téléphone la proposera tout seul à la connexion). Sans QG_DATA_KEY, les données chiffrées (clients, compta, mails) sont perdues.
2. Colle-les dans GitHub : dépôt cerveau, Settings, Secrets and variables, Actions.
3. QG_HOOK_SECRET va aussi dans les propriétés du script Google (HOOK_SECRET).
Ne régénère pas les clés une fois le QG en service.
